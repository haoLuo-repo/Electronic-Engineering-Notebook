# Electronic Engineering Notebook

> A personal knowledge management system for electronic engineering learning, engineering practice, and project development.

这是一个面向电子工程学习的个人知识库，用于记录、整理和沉淀大学阶段的专业学习过程。

本仓库围绕以下方向展开：

- 模拟电子技术（Analog Electronics）
- 电力电子技术（Power Electronics）
- C2000 / MCU 嵌入式开发
- PCB设计与硬件工程
- AI辅助学习工具
- 工程项目实践

通过：

**学习记录 → 知识整理 → 问题复盘 → 工程实践**

逐步构建属于自己的电子工程知识体系。
