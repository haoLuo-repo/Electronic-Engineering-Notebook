# 2026-08-24 Markdown 学习笔记

> 这篇笔记记录我目前已经接触到的 Markdown 语法，以及写 GitHub 学习日志时最需要的部分。  
> 黑色内容以我的原始认识为主，🔴 表示必要的补充或纠正。

## 一、我目前学到的语法

### 1. 标题

我原来的理解：`#` 表示字体和层级的变化，`#` 越多，标题层级越低。

🔴 **补充：** `#` 的主要作用是划分文档结构，而不只是改变字号；符号后要留一个空格。

```markdown
# 一级标题
## 二级标题
### 三级标题
```

### 2. 引用

我原来的理解：`>` 会让这一行文字以特殊颜色显示。

🔴 **纠正：** `>` 表示引用，具体颜色由 GitHub 或编辑器决定，不一定是绿色。

```markdown
> 这是我想特别记录的一句话。
```

### 3. 列表

我原来的理解：`-` 可以另起一项。

🔴 **补充：** 它表示无序列表；如果步骤有先后顺序，就使用 `1.`、`2.`、`3.`。

```markdown
- MOSFET
- 驱动芯片
- 采样电路

1. 检查 PWM
2. 检查驱动波形
3. 低压上电
```

### 4. 代码块

三个反引号可以把中间的内容单独放进代码框。

````markdown
```c
uint16_t duty = 500;
```
````

🔴 **补充：** 在开头写上 `c`、`python` 或 `bash` 等语言名称，可以显示语法高亮。短参数可以用一对反引号，例如 `TBPRD`。

### 5. 加粗

两个星号包住内容可以加粗：

```markdown
**这是重点**
```

### 6. 分隔线

三个短横线可以添加分隔线：

```markdown
---
```

### 7. 表格

我已经知道可以用 `|` 和 `---` 绘制表格：

```markdown
| 参数 | 含义 |
| --- | --- |
| TBPRD | 周期计数值 |
| CMPA | 比较值 |
```

🔴 **纠正：** Markdown 表格是网页表格，不完全等同于论文中的“三线表”。

### 8. 数学公式

我的理解是：Markdown 中的公式写法和 LaTeX 比较接近。

行内公式：

```markdown
Buck 的理想关系为 $V_o = D V_{in}$。
```

单独显示的公式：

```markdown
$$
D = \frac{V_o}{V_{in}}
$$
```

🔴 **补充：** GitHub 支持常用 LaTeX 数学语法，但 Markdown 本身并不是完整的 LaTeX 排版系统。

## 二、为了写学习日志，我还需要会的三种语法

```markdown
- [x] 完成今天的学习
- [ ] 整理遗留问题
- [ ] 明天继续验证
```

### 2. 链接

```markdown
[Texas Instruments 官网](https://www.ti.com/)
```

### 3. 图片

```markdown
![互补 PWM 波形](../Assets/pwm-waveform.png)
```

🔴 **补充：** 图片最好统一放进仓库的 `Assets` 文件夹，再用相对路径引用，避免本地能显示、GitHub 却无法显示。
