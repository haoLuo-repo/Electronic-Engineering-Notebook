# 综合示波器项目

## 项目内容

设计一个示波器，要求利用AD9288模块将所采集到的电压信号转换成为数字信号并通过HDMI显示波形到屏幕上，同时要测量和显示信号的频率。另外，我们还需用到实验三学到的软硬件数据交互的知识，实现一个基于RISCV APB3 的实时传图并由HDMI显示的系统。最终应呈现的效果为屏幕上能显示幅值和频率的测量结果、波形和自主选择的图像。

## 感受

我写过很长的关于本综合项目的复盘，我发现，之所以自己会花那么多无效的时间和精力在这件事情，总共有以下原因。
- 1.没有使用高效的AI
- 2.没有跟队友进行线下的面对面合作，导致自己只能深陷挫败而无能为力
- 3.不及时总结所学知识，没有把模块对应的代码和功能以及级联方式整理出来，导致知识一用就忘，很不成体系
- 4.很少自己写代码，动辄让AI代劳整段的代码，导致总是解决不了问题，自己也没学到代码书写的逻辑和规范
- 5.拖延，总是在有一点点起色后就退出，没有一鼓作气的决心和勇气（好在最后痛定思痛让自己破釜沉舟了一回，终于让这个实验划上了句号）
